## 2. 原型内容

`water-tea.html` 是单文件 HTML/CSS/JS，无网络依赖，包含：

- 顶部「饮水 / 茶」模块切换，两个模块共用同一编辑骨架。
- 饮水使用清澈蓝色变体；茶使用低饱和茶绿色变体。
- 实时摘要：本次份量、温度、口感/浓淡、今日次数与今日累计。
- 快捷份量、份量步进、饮水单位切换。
- 温度与口感选择；茶模块额外提供茶种、杯数、热量与自定义茶种。
- 今日记录列表。
- 底部固定保存区，保存后更新今日记录、摘要并显示提示。
- 浅色 / 深色切换，键盘焦点样式与 `prefers-reduced-motion` 降级。
- 响应式规则：移动端全屏、平板收窄并启用双栏表单、桌面双栏展示设备原型。
- 字体使用 `rem`，选项与按钮使用 `min-height` 和 `flex-wrap`，没有为文字选项写死高度。
