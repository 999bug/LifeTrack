## 2. 设计方向与交付内容

- 视觉方向为「运动轨迹 / 训练手账」：森林绿作为产品骨架，鲜明的青绿只用于运动模块的顶部摘要、类型选中态、图表与识别图标。
- 顶部周摘要展示本周分钟数、次数、运动天数、平均每次、最常见类型和最近一次；7 天柱状图按本周记录实时重算。
- 三类运动只使用现有范围：瑜伽 / 骑行 / 跑步；没有增加距离、配速、热量等业务字段。
- 录入区展示现有三项字段：类型、时长、强度。时长支持数字输入、±5 分钟步进、滑杆与 15/30/45/60/90 分钟预设。
- 最近记录可按全部 / 瑜伽 / 骑行 / 跑步筛选；记录行展示已有类型、时长与强度。
- 保存动作固定在视口底部，使用全局森林绿保存色；错误使用全局错误色，运动青绿不承担系统动作语义。
- 交互已实现：类型切换、时长输入 / 步进 / 滑杆 / 预设、强度切换、最近记录筛选、浅深色切换、200% 字号切换、保存提示，以及保存后周摘要和最近列表同步更新。

## 5. 交互验证

- 点击瑜伽：类型选中态从跑步切换为瑜伽。
- 点击 `+5` 后再拖动滑杆到 `60`：输入、滑杆、时长读数和固定保存区文案同步更新。
- 点击高强度：强度单选态更新，保存摘要显示「高强度」。
- 切换深色后再切 200%：主题与字号控制状态正确，页面无横向溢出。
- 保存：本周摘要从 `80 分钟 / 2 次` 更新为 `140 分钟 / 3 次`，最近记录从 4 条增加到 5 条，并出现保存成功提示。
- 筛选骑行：列表正确收敛为 1 条。
- 网络请求仅包含本地 HTML 文件本身，无外部字体、图片、脚本或样式依赖。
