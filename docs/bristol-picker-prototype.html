设计说明

照着图选，不用背分型

如厕后单手记录，用户不会记得「3 型和 4 型差在哪」。把七个形态一次摊开，用图形 + 两字短标签替代纯数字，选中后再补一句确认文案。

  1. 1
    七型一眼看全4 + 3 网格，不横向滚动。现状的横向 chip 行在手机上只能看到前四型，第 7 型要滑到底，等于让用户凭记忆选。
  2. 2
    颜色只做识别，不做装饰形态图统一用排便模块识别色 --toilet；选中态改用主色描边 + 勾选圆点 + 描述条，三重信号，不只靠颜色。分组用「偏干端 / 中间段 / 偏稀端」的轴向词，不贴诊断标签。
  3. 3
    允许不确定虚线「不确定 / 本项留空」卡与再点取消都回到未记录，对应 bristolType: Int?；它默认选中，与其它字段的「未记录」chip 口径一致。字段仍可空，统计里「未填写」继续单独计分母，不画成第 8 根柱。
  4. 4
    沿用既有壳层日期、时间、时区提示、五个详情字段、备注、取消 / 保存全部保持真实顺序与文案，只替换布里斯托那一块插槽内容。

组件规格

容器通用编辑器 AlertDialog，内容区仍可纵向滚动（heightIn(max=560.dp)）
网格4 列 × 2 行，间距 7px；200% 字号改 2 列（对齐 fontScale > 1.3 的既有分行逻辑）
卡片最小 92×? px，圆角 12px，触摸目标远超 44dp；图形 58×38，编号 12px，短标签 11.5px
状态默认 / 按下缩放 0.982 / 选中 2px 主色描边 + primarySoft 底 + 勾选 / 焦点环 2px
动效只保留 160ms 状态过渡与按下缩放，遵循「克制的动效」
无障碍每卡为带 aria-pressed 的按钮，读屏播报「4 型，光滑柔软，中间段」；图形对读屏隐藏
