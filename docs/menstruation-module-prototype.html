经期子应用
交互原型

按 14:03 的指示把经期页改成参考 App 的交互方式：日历置顶选日期，下方一行一行填当天内容，每行带图示，最后加一行日记。点行展开选项，即点即存，不再弹底部表单。

01 日历在上，选日驱动

经期页第一屏就是可翻未来月的日历。点任意日期，下方标题、起止动作与逐行表单整体切到那一天；未来日期只给只读提示，不编造记录。

02 一行一行填，内容有图示

流量 / 痛经 / 症状 / 心情 / 分泌物各占一行，行首是功能图示，已填值带等级格或表情图示。点行展开选项，选中即保存，同一天只记一条。

03 新增日记行

最后一行是日记，纸笔图示加多行文本，写当天的感受与作息。复用现有事件备注字段，不新增详情字段、不改备份格式；不引入图片与富文本。

点工具栏切浅 / 深色、200% 字体、三种数据场景；点日历换日期，点任意行展开填写，改周期 / 经期长度会立即重算预测日期。图示均为内联自绘 SVG，无外链、无渐变、无装饰 emoji。数据为确定性 mock，跨面板自洽。也可用 ?page=cycle&row=diary&scroll=form 直达日记行。
