按 13:39 拍板：点首页「记录月经」卡直接进入一个完整的经期子应用，首屏信息架构接近参考 App，让使用者无缝使用。全局布局与历史页不动，数据仍走同一套事件表。

01 点卡直接进子应用

首页「月经」模块卡与状态行都指向同一个「经期」页；卡片右下角由「记录」改为「打开」。快速记一条移到子应用首屏的「今天记一笔」主按钮。

02 首屏就是完整闭环

状态大卡、今天记一笔、大姨妈来了 / 走了、可翻未来月的经期日历、本周期简报、趋势与设置依次排布。抄的是信息架构与交互，视觉沿用 LifeTrack token。

03 边界与历史页不变

不做账号 / 云同步 / 社区 / 电商 / 资讯 / 孕产模式 / 推送。现有月历 require(offset <= 0) 禁止翻未来，历史页仍是列表 / 月历两态并带「本页不改」角标。

点工具栏切浅 / 深色、200% 字体、三种数据场景；点「今天记一笔」打开按天记录编辑器，点日历中过去的日期可直接补记该天，未来日期只给只读提示；改周期 / 经期长度会立即重算预测日期。数据为确定性 mock，跨页面自洽，无外链、无渐变。
