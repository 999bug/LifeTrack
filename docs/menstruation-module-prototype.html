月经模块
交互原型

按 2026-11-12 的布局诊断修正：不重设计全局布局，只加一条首页状态行和一个隐藏底导的「周期」二级页。数据为确定性 mock，跨页面自洽。

01 今天页只加一行

一句「经期第 N 天」加一个入口，不塞趋势图、不塞日历，6 个记录入口仍在首屏。模块停用时首页与 0.6.8 完全一致。

02 预测归到二级页

现有月历 require(offset <= 0) 禁止翻到未来，历史页两态也被定义为同一份数据的两种密度。所以未来经期日历、周期趋势、设置都放进新的「周期」页。

03 历史页保持不动

原型里可切到「历史」核对：仍是列表 / 月历两态，下一月按钮在本月禁用，页面带「本页不改」角标。

点工具栏切浅 / 深色、200% 字体、三种数据场景；点日历格子看当天状态，点「记录」打开按天记录编辑器，改周期 / 经期长度会立即重算预测日期。所有文案均为界面内文案，无营销措辞、无渐变、无外链。
