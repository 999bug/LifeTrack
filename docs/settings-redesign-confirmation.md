# 设置页重构 · 设计与实施记录

> 触发：用户 2026-11-09「设置页面帮我重新设计，现在看着比较乱」。
> 范围：设置页信息架构、记录项目管理独立页、首页入口排序、无障碍触摸目标。
> 顺带完成：B3（设置相关部分）、B5、B6 回归。

## 1. 原来的问题

1. **六张卡片平铺**：深色模式 / 记录项目 / 备份与恢复 / 数据与隐私 / 检查更新 / 关于，各自写一套内边距和字号，没有分区标题，看不出层级。
2. **记录项目管理占掉整屏**：四个模块 × （名称 + 副标题 + 两个箭头 + 开关），加一个模块就更长一截；上下移按钮只有 32dp，低于 48dp 触摸目标。
3. **备份卡片信息密度过高**：说明、明文警告、两个按钮、状态文字挤在同一张卡里，警告是整段红字。
4. **数据与隐私是一整段长文**，每次进设置都要滚过它。
5. **更新卡片**长期占一块，即使「已是最新」也显示完整卡片。
6. **排序并未真正生效**：`moveType` 改了 `sortOrder`，但首页入口是硬编码顺序，用户调了看不到变化。

## 2. 新结构

```text
设置
├─ 记录
│   └─ 记录项目        已启用 4 / 4 项 · 启用与排序  >
├─ 数据
│   ├─ 导出备份        全部记录与详情，导出为单个 JSON
│   ├─ 从备份恢复      会用备份替换当前全部记录（错误色）
│   ├─ [状态行]        仅在导出/恢复进行中或完成后出现
│   └─ 备份不加密（红色风险提示）
├─ 外观
│   └─ 深色模式        [Switch]
└─ 关于
    ├─ 版本            0.3.0
    ├─ 应用更新        当前版本 · 已是最新 / 发现新版本 [检查]
    └─ 数据与隐私      >（可展开，默认收起）
```

- 新增 `SettingsSection` / `SettingsRow` / `SettingsDivider` / `SettingsNote` 四个组件，
  新加设置项只写一行，不再各自决定排版。
- 记录项目管理独立成 `ModuleManagementScreen`：进入后隐藏底部导航，有返回箭头，
  每行 56dp、箭头与开关均为 48dp；大字号下箭头另起一行并带「调整顺序」标签。
- 更新合并成一行：标题 + 当前版本 + 检查按钮；只有「发现新版本 / 下载中 / 已调起安装器」才展开细节。
- 隐私说明改为折叠行，默认收起。
- 首页入口按 `trackTypes` 的 `sortOrder` 渲染，排序终于与设置一致。

## 3. 宽屏与无障碍

- 设置页与模块页正文 `widthIn(max = 640.dp)` + `wrapContentWidth(CenterHorizontally)`：
  平板 / 横屏下居中限宽，不再让一行文字横跨 1200dp。
- 行高 ≥56dp、所有图标按钮 48dp；`contentDescription` 补齐（返回、上移/下移、展开/收起）；
  分区标题加 `heading()` 语义；导出/恢复状态加 `liveRegion = Polite`；
  模块开关补充 `stateDescription`（已启用 / 已停用）。
- 深色模式整行可点（`Role.Switch` + 行点击），不只依赖右侧小开关。

## 4. 验收

| 项 | 结果 |
| --- | --- |
| 编译 / 单测 / lint | `assembleDebug` + 115 项单测 + `lintDebug` 全绿 |
| 100% 字体 | 设置页四段排布正常；记录项目页四行对齐，首行上移禁用 |
| 200% 字体 | 设置页行高自适应、无截断；模块页「调整顺序」+ 箭头另起一行；数据与隐私标题正常换行 |
| 2000×1200 平板视口 | 设置页正文限宽居中；月历 7 列等宽；统计/历史无溢出 |
| 1200×800 横屏 | 页面可滚动，无横向溢出 |
| 深 / 浅色 | 设置、首页、统计、历史均无 M3 默认紫色；卡片对比度正常 |
| 触摸目标 | uiautomator 实测：设置行 379×63dp、箭头 48×48dp、开关 52×48dp、导航项 97×80dp |
| 排序生效 | 模块页把「运动」上移后，首页入口与次数卡顺序同步变化 |
