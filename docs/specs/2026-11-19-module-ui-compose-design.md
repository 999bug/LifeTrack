# 记录模块 Compose 统一落地

> 日期：2026-11-19。状态：已批准。用户同意“统一骨架 + 模块主色”方案，并要求完成后发版。

## 1. 背景与目标

咖啡记录页已完成全屏点单笺改造并通过真实模拟器验证。其余记录模块已有高保真原型，本轮将视觉语言和录入骨架落到 Compose。

可验收目标：

- 饮水、茶、运动、排便、经期、亲密关系均采用统一页面骨架和各自模块色。
- 保留现有全部业务字段、校验、历史记录兼容与导航入口。
- 390dp 级手机、深色模式、200% 字体下无裁字或横向溢出。
- 完成模拟器主路径走查、截图、构建、405+ 单测和 lint。
- 全部验证通过后更新版本日志并发版 v0.7.1。

## 2. 非目标

- 不新增数据库字段、不升 Room、不修改备份 schema。
- 不把 HTML 原型中多余的业务字段带入 App；只复用既有模型。
- 不改底部导航、不抽全局 ViewModel、不升级依赖。
- 不修改咖啡页现有业务逻辑；只在必要集成时调整共享契约。

## 3. 设计约束

- 背景、surface、边框、文字、保存按钮、错误色由全局主题控制。
- 模块色用于顶部摘要、图标容器、选中态、图表和小标签。
- 经期使用砖玫瑰；亲密关系使用梅紫；保存按钮仍用全局森林绿。
- 编辑器优先使用全屏 Dialog，保持原函数签名，避免改导航。
- 不写固定文字高度；大字号使用 `heightIn`、FlowRow 或纵向降级。
