运动子应用
交互原型

按已确认的四个方向做：A 节奏型、共用「时长 + 强度」、首页整卡进子应用、界面只留瑜伽 / 骑行 / 跑步。这一版只做视觉与交互，不写 Compose。

01 先看节奏，再记录

首屏第一块是本周概览：次数、总时长、三类占比条、7 天节奏格。首页与统计页都看不到「这周断没断」，这是子应用存在的理由。

02 三类只差图标，不差字段

瑜伽 / 骑行 / 跑步共用类型、时长、强度、备注，差异只在图标、占比条与筛选。不引入距离字段，不推翻「不做热量或配速推算」的既有约定。

03 快记是主行动

三张类型卡点一下直接开弹层并预选类型，填完时长就保存。复用现有编辑器，不重造表单；保存后概览数字立即更新。

04 首页入口不动网格

运动卡留在快速记录网格里，整卡点击进子应用，右下角动作槽保留「记一次」直接记录。高频路径不多一次点击。

工具栏可切浅色 / 深色、常规 / 200% 字体、本周有记录 / 空态；点三张类型卡打开记录弹层，选时长与强度后点保存，概览与列表会真的变化；点「本期简报」展开指标；点类型 chip 过滤列表。
