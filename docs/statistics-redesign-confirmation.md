## 2. 必须先拍板的口径（最容易返工的地方）

### D1 · 周期怎么算

| 方案 | 说明 | 取舍 |
| --- | --- | --- |
| **自然周期（推荐）** | 自然周（周一为首日）/ 自然月 / 自然年，标题显示真实区间如「11月3日 — 11月9日」，可左右翻页看历史 | 符合"周报月报"的直觉，跨月跨年需要处理边界 |

### D2 · 年视图的主图形态

- **A · 12 根月柱（推荐）**：可读性最好，代码量最小
- B · 53×7 热力图：最酷、信息密度最高，但跨年周对齐（一年不是整数周）要单独处理
- C · 月柱 + 热力图切换：效果最完整，工期最长

### D3 · 多年数据

是否需要在年视图上下切年份（比如记录跨了 2025 / 2026）。**推荐需要**，否则去年的数据在年视图里永远看不到。

## 4. 「酷」的具体定义（不靠渐变堆料）

视觉主张：**暗夜仪表盘**。深色是设计主战场，浅色做同构降饱和版本。

具体手法：

1. **单色体系**：薄荷绿主色 + 中性灰阶，不引入第二强调色。
2. **等宽大数字**：Hero 用 tabular figures，56–64sp，字重 300，四周留白拉开对比。
3. **柱形语言**：柱宽 8–10dp、柱顶圆角 3dp；当前周期那根用 100% 主色 + 低透明描边外发光（**不用 blur shadow，会糊**）。
4. **背景网格**：32dp 间距、alpha 0.06 的 1px 网格线，制造仪表盘质感。
5. **卡片降噪**：改用 1dp 描边 + surface 微提亮，丢掉 M3 默认阴影。
6. **动效三件套**：数字 count-up 600ms、柱子逐根 clip-reveal（stagger 20ms）、周期切换 crossfade 220ms。
7. **颜色语义**：次数增减**不用红绿**——健康数据没有好坏，用中性色 + ↑↓ 箭头表达。

明确禁用（沿用你既有的 Anti-Slop 底线）：彩虹渐变、玻璃拟态、装饰性 emoji、外链图片、营销腔文案。

## 5. 交互

- 分段控件点击 ↔ 内容区左右滑动（HorizontalPager）双向同步。
- 点击某根柱 → 柱下浮出数值气泡，2s 自动消失；v1 不做下钻新页面。
- 空周期：图表区显示占位骨架 + 「这个周期还没有记录」，**不画一排 0 柱**。
- 数据由 Flow 驱动自动刷新，不做下拉刷新。
- 系统开启「移除动画」时（`ANIMATOR_DURATION_SCALE == 0`）跳过全部入场动画。

## 6. 技术方案与影响面

### 6.1 数据层

- 新增 `StatsPeriod`（WEEK / MONTH / YEAR）与 `StatsWindow`（start、end、label、prevStart、prevEnd）。
- **一次查询覆盖「上一周期起点 → 本周期终点」**，Kotlin 侧切分成当前/上期。理由：拆两条 Flow 会出现两段加载态闪一下。
- 年视图：daily counts 按月 `groupBy` 求和。
- 时段分布：Kotlin 侧用 `Instant + ZoneId(record.zoneId)` 还原小时，**不走 SQLite 的 `localtime`**——记录里存了当时的时区，SQL 会把它抹平。
- 不新增表、不新增迁移，Room schema 保持不动。

### 6.2 UI 层

- `StatisticsScreen` 重写，拆出 `StatsPeriodSwitcher` / `StatsHero` / `DailyBarChart` / `YearHeatmap` / `MetricGrid`。
- 图表用 Canvas 单次遍历绘制，避免 31 个 Composable 造成的 recomposition 抖动。
- 入场动画统一由一个 `Animatable<Float>` 驱动，**禁止每根柱各持一个 `animateFloatAsState`**。

### 6.3 依赖

- 不引第三方图表库（Vico / MPAndroidChart 都不引）：包体 + 风格不可控 + 与现有主题对不齐。
- 热力图若进 v1，仅需 `ui-graphics`（已在依赖中）。

### 6.4 兼容与边界

| 项 | 处理 |
| --- | --- |
| minSdk 26 | `java.time` 原生可用，无需 desugaring |
| targetSdk 36 | Scaffold 已处理系统栏 inset；沉浸头部需显式 `statusBarsPadding` |
| 字体缩放 200% | Hero 数字 `maxLines=1` + 降字号兜底，避免截断 |
| 360dp 窄屏 | 月视图 31 根柱每根仅约 6dp，需整列透明触摸区（48dp 高）兜底 |

## 11. 实施记录（2026-11-09）

按第 10 节推荐值落地，未新增依赖、未改 Room schema（只有新增查询，无迁移）。

落地内容：

| 文件 | 作用 |
| --- | --- |
| `core/model/StatsWindow.kt` | `StatsPeriod` / `StatsWindow` / `statsWindow()`。自然周（周一起）、自然月、自然年；offset 为绝对偏移，来回翻页不漂移 |
| `core/database/model/EventTimestamp.kt`、`TrackEventDao.observeEventTimestamps()` | 时段统计只查「时刻 + 时区」，不加载 detail |
| `feature/statistics/StatsAggregator.kt` | 纯函数聚合：总数、环比、日均、峰值、最长连续、常见 2 小时时段、柱状图数据 |
| `feature/home/MainViewModel.kt` | 一次查询覆盖「最远上一周期 → 最远本周期」，三个周期共用；`shiftStatistics()` 翻页，不允许翻到未来 |
| `feature/statistics/StatisticsScreen.kt` | 暗夜仪表盘重写：周期胶囊 + Pager 滑动、Hero 数字滚动、Canvas 柱图逐根 reveal、2×2 指标、洞察卡、空状态 |

实施中相对原设计的修正：

1. **年视图主指标改「月均」**：2 条记录 / 365 天显示「0.0 次」没有意义，改为按 12 个月平均。
2. **上期为 0 时不显示「较上期」**：否则「↑ 2 较上期」和洞察卡「本期首次留下记录」自相矛盾。
3. **跨年周标签改短格式** `2025/12/29 — 2026/1/4`：原全角格式会撑破顶部胶囊。
4. **字体放大 200% 的适配**：标题与胶囊改上下两行；常见时段退化为 `03–05`；图表轴标签行高按实际字号计算，避免裁切。

验收：`testDebugUnitTest` 全部通过；`assembleDebug` 通过；模拟器实测深/浅色、周/月/年、上下周期翻页、左右滑动切换、200% 字体。
